Data Structures & Algorithms — Beginner Summary

1. Time Complexity (Big-O): Measures how algorithm runtime grows as input size N increases. O(1) is constant, O(N) linear, O(N²) quadratic.

2. Hash Tables: Key-value store with O(1) average lookup. Python: dict. Java: HashMap.

3. Binary Search: Divide-and-conquer on sorted arrays. Time: O(log N). Best for finding elements quickly.

4. Dynamic Programming: Solve complex problems by breaking into overlapping subproblems. Key: memoization & tabulation.

Key Takeaways for Interviews:
  • Always start with brute force, then optimize.
  • Every Google/Amazon interview expects O(log N) or better.
  • Practice 2-3 LeetCode problems per day to build pattern recognition.
